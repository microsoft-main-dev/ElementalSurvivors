# Брендинг 4pots games

Исходники логотипов. В игру они попадают не отсюда: Roblox работает только
с загруженными ассетами, поэтому файлы заливаются в Roblox, а в код идут
их числовые Asset ID — в `src/Shared/Config/Branding.luau`.

Эти PNG лежат в репозитории как источник правды. Если ассет в Roblox
потеряется, его снимет модерация или понадобится вариант в другом размере —
пересобирать логотип с нуля не придётся.

| Файл | Размер | Где используется |
|---|---|---|
| `4potsgames_logo_square_512x512.png` | 512×512 | Экран загрузки (`BootController`) |
| `4potsgames_logo_horizontal_1024x256.png` | 1024×256 | Табличка у портала в лобби (`LobbyService`) |

Оба — PNG с альфа-каналом, фон полностью прозрачный, включая область
внутри кольца.

## Важно про контраст

Логотип нарисован тёмно-зелёным (`#175C3D`) и рассчитан на светлый фон.
Оба места, где он показывается, тёмные: экран загрузки `#122019`,
табличка `#1A241F`. Контраст тёмно-зелёного на почти чёрном — около 2:1,
то есть кольцо и слово «4pots» на таком фоне почти не читаются.

Поэтому под изображением рисуется светлая плашка. Альтернатива — отдельный
вариант логотипа «выворотка» (светлые штрихи вместо тёмных); тогда плашку
можно убрать, а файл положить сюда третьим.
